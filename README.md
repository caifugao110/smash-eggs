# 砸金蛋 · 学汉字

> 面向 **3–6 岁**小朋友的识字启蒙网页小游戏。砸开金蛋、听发音、认汉字，边玩边学。

在线试玩：<https://caifugao110.github.io/smash-eggs/>

**前端零依赖 · 可选本地童声服务器 · 一键启动 · 局域网共享 · MIT 开源**

---

## ✨ 特性

- 📚 **内容丰富**：36 个主题章节、**216 关**、**509 个**学习条目，涵盖汉字、词语、拼音、成语、古诗、英语、数学与安全常识。
- 🎮 **6 种玩法轮换**：找字 / 听音 / 拼音 / 看图 / 看词 / 挑战，难度逐关递增。
- 🔊 **真实童声朗读**：本地服务器用神经网络 TTS 合成真实儿童音色（女童 / 男童 / 卡通可爱），5 种音色预设，自然不生硬；音频缓存后离线可读。服务器不可用时自动退回系统语音。
- 🎵 **合成音效**：所有音效由 Web Audio API 实时生成，无需任何音频文件。
- 📳 **触屏友好**：手机 / 平板直接玩，支持点击、长按听读音、左右滑动切关、震动反馈。
- ⚙️ **高度可定制**：蛋数、目标数、玩法、拼音显示、主题配色、超大字体、音量等均可调。
- 📊 **学习报告**：星星、识字量、正确率、各章节掌握进度一目了然。
- 💾 **本地存档**：进度保存在浏览器 `localStorage`，支持导出备份；支持家长自定义字库。
- 🌙 **5 套主题**：阳光 / 薄荷 / 海洋 / 糖果 / 夜空。
- 🖥️ **一键本地服务器**：局域网内手机 / 平板 / 电脑共享同一套真实童声，无需逐台安装语音包。

## 🚀 快速开始

### 方式一：一键启动（推荐，真实童声 + 局域网访问）

**Windows**：双击 `start.bat`　**macOS / Linux**：`bash start.sh`

脚本会自动安装语音依赖并启动服务器，保持窗口开着即可：

| 访问方式 | 地址 |
|---|---|
| 本机 | <http://localhost:8000> |
| 手机 / 平板 / 其他电脑 | 启动时控制台打印的 `http://192.168.x.x:8000`（需连同一个 WiFi / 局域网） |

> 首次启动会自动在后台预生成全部学习条目的童声音频（约十几分钟），完成后**朗读完全离线**；
> 进度可访问 <http://localhost:8000/api/status> 查看。生成期间也能边玩边听，按需实时合成。
>
> ⚠️ 若手机连不上，多半是 Windows 防火墙拦截：首次启动时勾选「允许访问专用网络」，
> 或在「Windows Defender 防火墙 → 入站规则」中放行 Python 的 8000 端口。

### 方式二：直接玩（无服务器）

用浏览器打开 `index.html` 即可，无需安装、无需联网、无需构建。此时朗读使用浏览器内置语音（声音生硬），**真实童声需方式一**。

### 本地开发
```bash
git clone https://github.com/caifugao110/smash-eggs.git
cd smash-eggs
python server.py            # 推荐：带真实童声 + 局域网访问
# 或：python -m http.server 8000   # 纯静态，无服务器童声
```

### 部署
纯静态站点，可直接托管在 GitHub Pages、Vercel、Netlify、腾讯云静态网站托管等任意平台（无童声服务器时自动回退系统语音）。

### 自定义端口
```bash
python server.py --port 9000
```

## 🎯 玩法说明

1. 在关卡地图选择章节与关卡（完成前一关即可解锁下一关）。
2. 根据顶部提示（看字 / 听音 / 拼音 / 看图 / 看词），点砸对应的金蛋。
3. 砸对会朗读该字、撒彩纸并收集字卡；砸错不扣分，可以一直试。
4. 找齐所有目标字即可过关，根据错误次数获得 1–3 颗星。
5. 星星解锁后续关卡，字卡自动收藏，点击即可重听。
