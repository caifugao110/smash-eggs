# 砸金蛋 · 学汉字

> 面向 **3–6 岁**小朋友的识字启蒙网页小游戏。砸开金蛋、听发音、认汉字，边玩边学。

在线试玩：<https://caifugao110.github.io/smash-eggs/>

**零依赖 · 纯前端 · 完全离线可用 · MIT 开源**

---

## ✨ 特性

- 📚 **内容丰富**：36 个主题章节、**216 关**、**509 个**学习条目，涵盖汉字、词语、拼音、成语、古诗、英语、数学与安全常识。
- 🎮 **6 种玩法轮换**：找字 / 听音 / 拼音 / 看图 / 看词 / 挑战，难度逐关递增。
- 🔊 **童声朗读**：自动优先选用系统中文女声，提供 4 种声音风格（甜美童声、超级萌音、温柔姐姐、自然朗读）。
- 🎵 **合成音效**：所有音效由 Web Audio API 实时生成，无需任何音频文件。
- 📳 **触屏友好**：手机 / 平板直接玩，支持点击、长按听读音、左右滑动切关、震动反馈。
- ⚙️ **高度可定制**：蛋数、目标数、玩法、拼音显示、主题配色、超大字体、音量等均可调。
- 📊 **学习报告**：星星、识字量、正确率、各章节掌握进度一目了然。
- 💾 **本地存档**：进度保存在浏览器 `localStorage`，支持导出备份；支持家长自定义字库。
- 🌙 **5 套主题**：阳光 / 薄荷 / 海洋 / 糖果 / 夜空。

## 🎯 玩法说明

1. 在关卡地图选择章节与关卡（完成前一关即可解锁下一关）。
2. 根据顶部提示（看字 / 听音 / 拼音 / 看图 / 看词），点砸对应的金蛋。
3. 砸对会朗读该字、撒彩纸并收集字卡；砸错不扣分，可以一直试。
4. 找齐所有目标字即可过关，根据错误次数获得 1–3 颗星。
5. 星星解锁后续关卡，字卡自动收藏，点击即可重听。
